// R&D Goals

연구개발과제의 최종 목표

데이터 집약 응용 지원을 위해 고대역폭, 확장성, 고가용성을 제공하는 AI 반도체 지원 병렬 파일시스템 및 멀티모달 생성형 모델을 위한 데이터 플랫폼 개발

세부 목표 · 주요 기능

01

In-Storage Computing 환경에서 성능 최적화 및 모듈 이식 지원 기능 제공

02

고속 병렬 입출력 처리 및 ML 프레임워크 연동 최적화 지원 기능 제공

03

eBPF 기반 성능 및 장애 예측을 위한 메트릭 수집·모니터링 기능 제공

04

데이터 접근 패턴 분석 기반 자원 확장 및 최적화 기능 제공

05

스토리지 노드 및 클러스터의 무중단 증설과 안정화 지원 기능 제공

End Product
  • 고속 병렬 파일 시스템 지원 스토리지 노드 구성 방법서
  • In-Storage Computing 및 모듈 이식 요구사항 분석서
  • 멀티모달 데이터 최적화 객체 저장소 스토리지 아키텍처 요소 기술 분석서
  • 페타급 SSD를 위한 I/O 스택 최적화 기술 분석서
  • CXL 프로토콜 기반 병렬 파일 시스템 최적화 적용 모듈 (SW)
  • CXL3.1 스위치 기반 FPGA 최적화 (SW)
  • 하이브리드 PMEM 기반 메타데이터 가속 처리 모듈 (SW)
  • OLTP 워크로드 처리 최적화를 위한 데이터 배치 및 무효 데이터 관리 모듈 (SW)
  • 멀티모달 데이터 거버넌스 관리 모듈 및 외부 연동 API 모듈 (SW)
  • 차세대 데이터 센터 최적화 객체 저장소 기반 병렬 파일시스템 시제품 (SW)
  • AI-Powered Storage 지원 고성능 병렬 파일 시스템 엔진 모듈 (SW)
