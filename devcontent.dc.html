기관별 주요 개발내용

GitHub 조직에 공개된 레포지토리를 기준으로 정리한 개발 파트입니다. 기관명·역할 배정은 연구개발계획서 확인 후 각 카드의 상단 라벨에 반영합니다.

한국전자기술연구원 · PART 01

병렬 파일시스템 코어 개발

DAOS 스토리지 스택(클라이언트 라이브러리·스토리지 엔진·컨트롤 플레인)을 기반으로 AuroraFS 코어를 구성합니다. AI 워크로드 특성에 맞춘 메타데이터 관리, 네임스페이스, POSIX 호환 계층(dfuse) 확장을 담당합니다.

DAOS-core
한국전자기술연구원 · PART 02

유저스페이스 고속 I/O 스택

SPDK 기반 커널 우회 I/O 경로를 확보하고 NVMe·NVMe-oF 전송 계층을 튜닝합니다. 폴링 모드 드라이버와 AuroraFS 스토리지 엔진 간 연동 인터페이스를 개발합니다.

spdk
한국전자기술연구원 · PART 03

eBPF 데이터로더 개발

AuroraFS에서 사용되는 eBPF 기반 데이터 로더를 개발합니다. 커널 공간에서 데이터 접근 패턴을 관측·제어하여 AI 프레임워크로의 데이터 공급 경로를 최적화합니다.

Aurora_Dataloader
한국전자기술연구원 · PART 04

In-Storage Computing 프로토타입

nbdkit Python 플러그인 기반으로 NBD 계층 위의 경량 ISC 읽기/쓰기 프로토타입을 구현합니다. 쓰기 데이터의 zlib 청크 압축, 청크 메타데이터 인덱싱, QEMU·nbd-client 연동 검증을 수행합니다.

nbdkit-plugin
한국전자기술연구원 · PART 05

AI 기반 이상탐지 · 데이터 증강

AuroraFS 운영 데이터를 학습하여 시스템 이상 징후를 탐지하는 Anomaly Detection 알고리즘과, 파일시스템 데이터 증강(Data Augmentation) 모델을 개발합니다.

Aurora_AD Aurora_DA
