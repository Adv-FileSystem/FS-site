# 고속병렬파일시스템 웹페이지 (AuroraFS)

AI 반도체 클라우드를 위한 고속 병렬 파일시스템 기술개발 프로젝트 소개 웹사이트입니다.

## 페이지 구성

- `index.html` — 프로젝트 개요
- `goals.dc.html` — 목표
- `tech.dc.html` — 원천기술
- `devcontent.dc.html` — 개발내용
- `github.dc.html` — GitHub 저장소 및 통계, 저장소 등록 신청
- `members.dc.html` — 커뮤니티(참여 기관)

## 배포

GitHub Pages로 배포되어 있습니다 (`Settings → Pages`, main 브랜치 / root).

## 저장소 등록 신청 및 승인

과제 참여 기관은 `github.dc.html` 하단의 **저장소 등록 신청** 양식으로 GitHub 저장소를 직접 등록할 수 있습니다.

- 신청 항목: 저장소 URL, 저장소 이름, 개발 내용 설명, 기관명, 담당자 성명·이메일
- 접수된 신청은 승인 대기(`pending`) 상태로 저장되며 웹페이지에는 표시되지 않습니다.
- 관리자 로그인 시 저장소 섹션 위에 **승인 대기 목록**이 나타나 승인 또는 반려(사유 입력 후 보관)를 처리할 수 있습니다.
- 승인된 저장소는 저장소 목록에 기관명 배지와 함께 표시되고 상단 통계에 합산됩니다. 카드 하단의 **승인 전으로 되돌리기** 버튼으로 다시 대기 상태로 돌릴 수 있습니다.
- 담당자 성명·이메일은 내부 확인용으로만 사용하며 웹페이지에 게시하지 않습니다.

## 참고

- GitHub 통계(Stars, Forks, Commits, Language 등)는 Supabase Edge Function을 경유해 GitHub API에서 가져옵니다. 인증 토큰을 사용하므로 시간당 5,000회까지 요청할 수 있습니다.
- 커밋 합계는 외부 오픈소스를 fork한 참조용 저장소(spdk, DAOS-core)를 제외한 자체 개발 저장소 기준입니다.
- 관리자 로그인, 본문 수정 저장, 저장소 등록 신청·승인은 Supabase(`custom_repos` 테이블)와 연동되어 있습니다.
- 관리자 모드에서는 본문을 직접 수정할 수 있으며, 헤더의 **저장하기** 또는 **저장하지 않고 닫기**(수정 내용을 되돌림)를 선택할 수 있습니다.
