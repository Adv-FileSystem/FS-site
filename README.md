# 고속병렬파일시스템 웹페이지 (AuroraFS)

AI 반도체 클라우드를 위한 고속 병렬 파일시스템 기술개발 프로젝트 소개 웹사이트입니다.

## 페이지 구성

- `index.html` — 프로젝트 개요
- `goals.dc.html` — 목표
- `tech.dc.html` — 원천기술
- `devcontent.dc.html` — 개발내용
- `github.dc.html` — GitHub 저장소 및 통계
- `members.dc.html` — 커뮤니티(참여 기관)

## 배포

GitHub Pages로 배포되어 있습니다 (`Settings → Pages`, main 브랜치 / root).

## 참고

- GitHub 통계(Stars, Forks, Commits, Language 등)는 브라우저에서 GitHub API를 직접 호출합니다. 인증 없는 요청은 시간당 60회로 제한되어, 방문이 몰리면 일시적으로 0으로 표시될 수 있습니다.
- 관리자 로그인 시 저장소 추가 등 일부 기능은 Supabase와 연동되어 있습니다.
